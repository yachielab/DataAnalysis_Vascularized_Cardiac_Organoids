# Human cardiac organoids with coronary-like vasculature promote cardiomyocyte maturation and post-infarct functional recovery

This is data analyses workspace for manuscript "Human cardiac organoids with coronary-like vasculature promote cardiomyocyte maturation and post-infarct functional recovery". 

- scRNA-seq analyses
  - Preprocessing and embedding: CCO04.ipynb Section 1 (with sc_rnaseq.yml)
  - UMAPs, dot plots, cell-type distributions visualization: CCO12.ipynb Section 1 (with sc_rnaseq.yml)
  - Cardiomyocytes and endothelial cell specific analyses: CCO12.ipynb Section 2 (with sc_rnaseq.yml)
  - DEG and volcano plots: CCO12.ipynb Section 3 (with sc_rnaseq.yml)
  - RNA velocity: CCO12.ipynb Section 4 (with scVelo.yml)
  - CellPhoneDB: CCO12.ipynb Section 5 (with cellphonedb.yml)
  - endothelial cell label transfer: CCO08.ipynb Section 5 (with sc_rnaseq.yml)
- bulk RNA-seq analyses
  - CCO14.ipynb (with bulk_rnaseq.yml)
- VisiumHD analyses
  - CCO11.ipynb (with sc_rnaseq.yml)
